Rule used for `startTime`: the start time the organizer gives for the event named in `name`. Where the tree lighting has its own time, that time is listed below and not in the record.

- https://www.visitdowntownjohnstown.com/johnstownjingle: "Johnstown Jingle", "Sunday, December 6, 2026", "2pm - 5pm", "Tree Lighting at 5:30pm". - Filed as a **tree-lighting** because the Jingle is the town's community tree lighting. `name` is the event's name, "Johnstown Jingle". `startTime` is "2 pm", when the Jingle starts; **the tree lighting itself is at 5:30 pm**. Change `startTime` to "5:30 pm" if records should carry the lighting time.
