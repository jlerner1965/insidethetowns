# Feeds found among html/manual sources

Probe run 1 November 2026 with user agent `InsideTheTowns-linkcheck/1.0 (+https://insidethetowns.com/editorial/)`, curl, 20 s timeout, redirects followed, robots.txt read before the first request to each host (scripts/lib/robots.ts parser; Crawl-delay honoured), one request at a time per host. The probe's scripts and raw results were scratch files and are not kept.

"Upcoming" = occurrences starting on or after 2 November 2026 00:00 Denver time and before 2 March 2027 (ingest's own 120-day horizon), cancelled items excluded, counted with the repo's own readers (scripts/lib/feeds/ical.ts, rss.ts, tribe.ts). For The Events Calendar's JSON API the count is the API's `total` for that window. Feeds were fetched once each.

Sources probed: 271 (type html or manual, status confirmed or proposed). Table 1 rows with upcoming events: 29; feeds that exist but are empty or past-only: 12.

In short: of the 29 table rows with upcoming events, 26 are distinct feed URLs (cityofgolden-gov-parks, daconoco-gov-parks and one Boulder County row repeat another row). Leaving out Honnibrook (already known) and Boulder County's calendar (already ingested as bouldercounty-gov), **24 feeds are newly found**. Three of those add little: broadwayworld.com's calendar is national Broadway openings, and douglasco.gov/calendar and longmontcolorado.gov/events are calendars the repo already reads in another form. Of the remaining 21, **17 can be read by ingest's existing readers as they stand** (ical; rss with CivicPlus, LibCal or Modern Events Calendar elements; tribe json), and **4 need a small reader first**: Golden's Revize JSON, the two Jefferson County Library BiblioCommons RSS feeds (dates in `bc:` elements), and Visit Longmont's Simpleview RSS (dates only in pubDate). Many more calendars exist but sit behind robots.txt (Google Calendar, Tockify, Squarespace, LibraryCalendar, Finalsite): section 3a lists them for the editor's `robots: subscribe` call.

Known, not re-probed: Armadillo Ranch (Manitou Springs), `https://tockify.com/api/feeds/ics/dilloranch`. tockify.com/robots.txt disallows `/api/` for all agents, so it was not fetched here; it needs `robots: subscribe` like the other Tockify feeds in 3a. Honnibrook (Castle Rock) was fetched once and has a row below.
Request budget: most sources took one to three requests (page, one events page, one feed). Five took a fourth, to find a branch or data URL the page only names in script: Golden (Revize index.js, then the JSON), High Plains LibCal for Erie (the building list, then the RSS), Jefferson County Library (one RSS per branch, GN and EV), Clearview (the Communico feed), Nederland LibCal.
