The Development Code was last repealed and replaced in 2025. The staff memo describes this rewrite as the corrections and clarifications the Town's attorneys and staff have found since, with every section condensed and reformatted. The changes it lists include a new P, Public Use, zone district; the Mountain Avenue and 1st Street overlay districts moved into the zoning section; technical guides for annexation, zoning and subdivision applications; clearer vesting options; sign rules revised to follow recent Supreme Court rulings; and a fee amount taken out of the code and left to the Town's annual fee schedule. The same hearing takes up Ordinance 1394, an emergency ordinance updating the code's reference to Larimer County's flood insurance map. [What's being built in Berthoud](/articles/whats-being-built-in-berthoud/) lists the projects these rules apply to.
