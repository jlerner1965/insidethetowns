# Frederick

Frederick is covered by Inside Carbon Valley (carbonvalleyguide.com), the guide
to Frederick, Firestone and Dacono, and is not a guide of its own (the
restructure brief of 12 November 2026; DECISIONS.md, "Carbon Valley is the
guide; Frederick is covered by it"). Everything Inside Frederick held is in
`content/carbon-valley/`, at the same slugs; new Frederick content goes there.

Every path on insidefrederickco.com redirects to the same path on
carbonvalleyguide.com (vercel.json). `images/` stays for the holding page the
old project still builds, with its row in IMAGE_LICENSES.csv. Nothing else here
is built or audited.
