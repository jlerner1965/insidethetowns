The City’s news release calls the new code "the first comprehensive rewrite of the code in nearly 40 years," aligned with the Legacy Lafayette Comprehensive Plan and shaped by community input, and says an updated zoning map was adopted with it. Before February 1 the City plans a follow-up ordinance "to improve clarity and consistency" in the text. The adopted code and the zoning map are posted on the Lafayette Listens project page.
