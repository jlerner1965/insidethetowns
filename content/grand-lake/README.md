# Grand Lake: retired

Inside Grand Lake was retired on 30 October 2026 (DECISIONS.md, *Grand Lake
retired*). There was no neighbouring guide to fold it into, so its events,
places, staged items, articles, weekly notes and sources were removed, not
moved; git history keeps them, should the guide reopen.

Every path on insidegrandlake.com redirects to insidethetowns.com
(vercel.json). The Vercel project `insidegrandlake` still builds with
`TOWN=grand-lake` so it keeps serving those rules; what it builds is one
holding page saying the guide has closed. `images/` stays with its rows in
`IMAGE_LICENSES.csv`, and `images/hero.jpg` because the config names it.

Do not add content here. Reopening is a decision first, then a revert.
