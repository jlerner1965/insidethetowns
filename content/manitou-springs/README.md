# Manitou Springs: retired

Inside Manitou Springs was retired on 3 November 2026 (DECISIONS.md, *Evergreen, Manitou
Springs and Clear Creek retired*). There was no neighbouring guide to fold it
into, so its events, places, staged items, articles, pages, weekly notes and
sources were removed, not moved; git history keeps them, should the guide
reopen.

Every path on insidemanitousprings.com redirects to insidethetowns.com
(vercel.json). The Vercel project `insidemanitousprings` still builds with
`TOWN=manitou-springs` so it keeps serving those rules; what it builds is one
holding page saying the guide has closed. `images/` stays with its rows in
`IMAGE_LICENSES.csv`, and `images/hero.jpg` because the config names it.

Do not add content here. Reopening is a decision first, then a revert.
